# 红人资源库 / 进度看板 —— 部署说明

零依赖 Node 服务，跟插件后端**同一台 VPS、同一个 `~/kol-data/` 数据目录**，独立端口、独立 systemd 服务，**不动现有 `kol-assistant`**。

## 1. 代码上 VPS

本工具在 `apps/roster/`。`main` 是部署分支，所以先把功能分支合并到 main（你确认后），VPS 再 `git pull`：

```bash
cd /home/ubuntu/kol-repo
git pull origin main
```

## 2. 建 systemd 服务

**直接复制下面整段到 VPS 跑**（会自动写好 `/etc/systemd/system/kol-roster.service`、自动找 node 路径、启动、验证）。
注意：下面是**命令**，整段粘进去执行，不是让你手动建文件。

```bash
NODE=$(which node)
sudo tee /etc/systemd/system/kol-roster.service > /dev/null <<EOF
[Unit]
Description=KOL Roster (红人资源库 + 进度看板)
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/kol-repo/apps/roster
Environment=ROSTER_PORT=3220
Environment=KOL_DATA_DIR=/home/ubuntu/kol-data
ExecStart=$NODE server.js
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now kol-roster
curl -s localhost:3220/health   # 看到 {"ok":true,...} 就成功
```

> 想加口令保护（推荐，因为含付款信息）：在上面 `Environment=KOL_DATA_DIR=...` 下面加两行
> `Environment=KOL_ASSISTANT_TOKEN=你的团队口令`（与插件同一个）和
> `Environment=KOL_ASSISTANT_ADMIN_TOKEN=你的管理员口令`（领导标优质用），改完
> `sudo systemctl daemon-reload && sudo systemctl restart kol-roster`。不设 = 全放行。

更新代码后：`git pull origin main && sudo systemctl restart kol-roster`。

## 3. 访问

- 资源库：`http://<VPS-IP>:3220/`
- 进度看板：`http://<VPS-IP>:3220/board`

确保安全组/防火墙放行 3220（或用 nginx 反代到域名 + HTTPS）。设了团队口令的话，页面首次会弹出来让填，存浏览器本地。

## 4. 两个可选配置文件（放 `~/kol-data/`）

- `roster-team.json`：`insId → 实习生名`，解决「一人两号」显示成名字。例：
  ```json
  { "ins_aaa": "小王", "ins_bbb": "小王", "ins_ccc": "小敏" }
  ```
- `roster-overrides.json`：领导标的「优质」，**网页自动写**，不用手建。

## 5. 数据从哪来

插件（v0.28.0+）把各人浏览器数据备份到 `~/kol-data/backups/<insid>.json`，本服务只读它们、合并展示。**实习生在档案卡填了新字段、数据才会出现。**

- **是不是合作**靠 `isCollab()` 看内容判断（产品前缀 / 带币种价格 / 平台 · 条款关键词），不靠插件 `isGroup`（它把"你+红人"两人群误判成私聊）。纯人名 DM / 便签不进表。
- **对接人 / 产品兜底**：没在插件「服务器设置」填身份的同学，用 insid 文件名前缀 + 插件存的 `myProduct` / `myHandle` 逐级兜底（代码里 `ownerName` / `prodOfInsid` / `prefixCode`），对接人列和产品列不留空。
- **产品共 9 个**（`PRODUCTS` 常量）：`generic` 之外 `recco/rythmix/aicatch/vivavideo/wisemeal/vivacut/rymo/inspo`，对应代码 `RC/RM/AC/VA/WM/VC/RY/IN`（`aicatch` 拼写别名 `aictach` 也映射 AC）。两页都有「总表 + 各产品 tab」。
